# Superadmin PHC Directory

The PHC directory gives platform Superadmins an authoritative view of registered Primary Healthcare Centres.

## Find a PHC

1. Open **Administration → PHC Directory**.
2. Search by clinic name, LGA, or state.
3. Select **Open** to view the PHC's database-derived staff and patient counts and its staff roster.

The summary cards show registered PHCs, staff, patients, and represented states. They do not estimate device activity or sync health.

## Access and safety

Only authenticated Superadmins can query the platform-wide directory. The directory uses no AI and provides administrative counts only; it does not expose patient-level clinical details.
