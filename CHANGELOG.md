## 0.1.5 — Initial Public Release

This is the foundational release of ClinicFlow — an offline-first, AI-powered hospital management system for rural Primary Healthcare Centres (PHCs) in Nigeria.

### Core Platform

- feat: initialize project with SvelteKit + Svelte 5, Tailwind CSS v4, shadcn-svelte, and Dexie local-first database
- feat: implement full PostgreSQL schema with Drizzle ORM (patients, encounters, vitals, queue tickets, pharmacy inventory, prescriptions, lab requests, reminders, appointments, pregnancy records, family relationships, triage rules, audit log, and sync infrastructure)
- feat: integrate Better Auth for role-based access control (receptionist, nurse, doctor, pharmacy, admin, superadmin)
- feat: implement 4-digit hashed PIN for kiosk/tablet login
- feat: add device registration and approval flow for PHC hardware management

### Patient Management

- feat: implement POS-style patient registration with NIN/phone lookup
- feat: add patient profile view with medical history timeline
- feat: implement family health tracking (household grouping, guardian relationships)
- feat: add NDPR patient consent gate on registration with full compliance documentation
- feat: implement patient QR card generation for rapid clinic ID scanning

### Queue Management

- feat: implement priority-sorted queue board (Red → Amber → Green → Unassigned)
- feat: add real-time queue ticket creation and status updates via Svelte 5 reactive stores
- feat: implement nurse "Call Next" and doctor "Start Consultation" queue flow
- feat: add No-Show and Done ticket management with dropdown actions

### Triage & Vitals

- feat: implement nurse vitals recording (temperature, BP, pulse, weight, SpO2)
- feat: implement WHO-aligned configurable triage rules engine (threshold-based Red/Amber/Green scoring)
- feat: add pregnancy-aware triage rules (elevated BP thresholds for pregnant patients)
- feat: implement 2-step vitals workflow with QR scanner patient identification

### Doctor Consultation

- feat: implement doctor consultation dashboard with queue and patient search
- feat: add chief complaint recording with raw voice transcript support
- feat: implement doctor notes and encounter creation
- feat: add lab request ordering from consultation view

### Pharmacy

- feat: implement pharmacy dispensation queue and inventory management
- feat: add low-stock threshold alerts and restock request workflow
- feat: implement prescription dispense tracking with dispensed-by audit trail
- feat: add category-aware inventory (antimalarial, ARV, vaccine, family planning)

### AI Features

- feat(ai): implement Dr. Assist clinical decision support using Gemini 2.5 Pro with WHO PHC guidelines, differential diagnosis, and emergency red-flag detection
- feat(ai): implement RxBrain pharmacy safety checker for drug interactions, contraindications, and pregnancy-aware dosage warnings
- feat(ai): implement AI SOAP Note Generator with voice dictation, full clinical context injection, and PII-stripping NDPR compliance
- feat(ai): implement Patient Risk Stratification (0–100 deterioration score) with longitudinal vitals trend analysis, real-time doctor alerts, and optional AI auto-escalation flag

### LAN & Sync Architecture

- feat: implement offline-first Dexie local database with Last-Write-Wins sync conflict resolution
- feat: implement sync engine with cross-tab BroadcastChannel coordination
- feat: implement LAN relay server for multi-device clinic networking without internet
- feat: implement cloud uplink config for optional secure sync when connectivity returns
- feat: add Bonjour/mDNS server discovery for zero-config device pairing

### SMS & Reminders
